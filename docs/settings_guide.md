# 设置说明

[返回用户指南](./user_guide.md)

设置对话框分为四个页面：快捷键设置、参数设置、质检忽略 和 抠图。

窗口左下角有一个 **恢复默认设置** 按钮，点击并确认后会删除配置文件
`~/.labelforge.json`，把快捷键、主题、语言、参数、记忆记录和裁剪模板全部还原为出厂默认。

---

## 快捷键设置

在「设置」对话框的「快捷键设置」页面，可自定义以下快捷键。点击输入框后按键即可绑定，支持 `Ctrl+`、`Alt+`、`Shift+` 组合键。

| 操作 | 默认值 | 说明 |
|------|--------|------|
| 撤销 | `Ctrl+Z` | 撤销上一步操作 |
| 重做 | `Ctrl+Y` | 重做 |
| 显示网格线 | `Ctrl+G` | 显示/隐藏网格辅助线 |
| 显示BOX | `R` | 显示/隐藏检测框边框 |
| 显示标签名 | `T` | 显示/隐藏标签名称 |
| 显示置信度 | `Y` | 在类别名后显示推理置信度 |
| 显示贴图名 | `F` | 显示/隐藏贴图文件名 |
| 自动保存B | `G` | 切换自动保存合成图 |
| 自动保存P | `H` | 切换自动保存 JSON |
| 绘制检测框 | `W` | 进入水平检测框绘制模式（按 `Q` 退出） |
| 绘制多边形 | `P` | 进入分割多边形绘制模式（按 `Q` 退出） |
| 标注关键点 | `K` | 进入关键点标注模式（按 `Q` 退出） |
| 绘制旋转框 | `O` | 进入旋转框（OBB）绘制模式（按 `Q` 退出） |
| 顺时针旋转 | `Z` | 选中旋转框后顺时针旋转一个步长 |
| 逆时针旋转 | `X` | 选中旋转框后逆时针旋转一个步长 |
| 退出绘制 | `Q` | 取消绘制 |
| 下一张 | `D` | 下一张背景图 |
| 上一张 | `A` | 上一张背景图 |
| 删除选中 | `E` | 删除选中的检测框/贴图 |
| 适应视图 | `Ctrl+F` | 适应视图 |
| 放大 | `Ctrl++` | 放大画布 |
| 缩小 | `Ctrl+-` | 缩小画布 |
| 移除图片 | `Ctrl+Shift+D` | 移除当前图片到 `_delete_` |
| 恢复图片 | `Ctrl+Shift+R` | 从 `_delete_` 恢复图片 |
| 删除标签 | `Ctrl+Shift+Z` | 直接删除标签列表中选中的标签，不弹确认框 |
| 缓存槽1 | `1` | 粘贴缓存槽1中的检测框 |
| 缓存槽2 | `2` | 粘贴缓存槽2中的检测框 |
| 缓存槽3 | `3` | 粘贴缓存槽3中的检测框 |

> 缓存槽快捷键可自定义修改；移除路径视图下绘制类快捷键（`W`/`P`/`K`/`O`）与删除选中（`E`）失效。
> 绘制多边形时还可用 `Backspace` 撤销最后一个顶点、`Enter` 完成绘制、`Esc` 取消；这些为绘制过程中的固定按键，不在可配置列表中。

## 参数设置

在「设置」对话框的「参数设置」页面，可调整以下参数。

### 文件名前缀

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 添加文件名前缀 | 开 / 关 | 开 | 保存时文件名是否添加前缀，前缀值可在此修改（默认 `paste`） |

### 窗口放大器

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 窗口放大器倍率 | 0.8 ~ 3.0 | 2.0 | 放大预览区域的缩放倍率 |
| 窗口放大器尺寸 | 80 ~ 400 px | 160 | 放大预览窗口的尺寸 |
| 放大器显示位置 | 侧边 / 鼠标中心 | 侧边 | 侧边：放大窗口在鼠标右下方偏移显示；鼠标中心：以鼠标为中心显示，始终可见 |

### 网格辅助线

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 网格线粗细 | 1 ~ 10 | 1 | 网格线宽度（像素） |
| 网格线灰度 | 0 ~ 255 | 120 | 网格线透明度，0 为完全透明，255 为完全不透明 |

### 状态栏

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 状态栏类别数 | 1 ~ 20 | 3 | 状态栏最多显示的标签类别数量 |

### 检测框

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 类别名字号 | 5 ~ 15 | 9 | 检测框标签名（含置信度）的字体大小，画布上按设置值直接显示，不随缩放或图片尺寸变化 |
| 标签名位置 | 框外侧 / 框内侧 | 框外侧 | 标签名显示在检测框外侧或内侧 |
| 缩放句柄大小 | 7 ~ 15 | 8 | 检测框四角手柄的尺寸（同时影响贴图句柄） |
| 多边形最大点数 | 3 ~ 64 | 32 | 分割多边形可添加的最大顶点数 |
| 框线粗细 | 1 ~ 4 | 1.0 | 检测框和贴图的边框宽度 |

### 移动与缩放

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 移动步长 | 1 ~ 5 | 1 | 方向键（←↑→↓）移动选中的检测框或贴图的步长（像素） |
| 检测框缩放步长 | 0.01 ~ 0.30 | 0.05 | 在检测框内滚动滚轮时的整体缩放比例步长 |
| 贴图缩放步长 | 0.01 ~ 0.30 | 0.15 | 在贴图内滚动滚轮时的整体缩放比例步长 |
| 单侧位移像素 | 1 ~ 50 | 5 | 在检测框外滚动滚轮时，调整距离鼠标最近一条边的位移像素 |
| 旋转角度步长 | 1 ~ 6 | 1 | 选中旋转框按 `Z`/`X` 时单次旋转的角度（度） |

> 检测框缩放步长只控制检测框滚轮缩放，贴图缩放步长只控制贴图滚轮缩放，两者独立。

### 标注十字线

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 十字线粗细 | 0.5 ~ 3.0 | 1.0 | 标注模式下十字线的宽度 |
| 十字线透明度 | 0 ~ 255 | 160 | 十字线的透明度 |
| 十字线颜色 | 色值选择 | `#00FF80` | 点击色块按钮选择颜色 |

十字线仅在标注模式、鼠标位于画布内且背景图已显示时出现。

## 质检忽略

「标注质检」中被忽略的问题会持久化到配置，此页用于统一管理：

- 列表显示所有已忽略规则，格式为 `问题类型 · 规则`（`*` 表示整类忽略，其余为按 `detail` 精确匹配）
- **移除选中** — 删除选中规则，该问题将重新出现在质检结果中
- **清空全部** — 删除所有忽略规则
- 点击「保存」生效，同时同步到已打开的质检弹窗

> 质检弹窗中右键「忽略此项 / 忽略此类问题」也会写入此页。忽略规则保存在 `~/.labelforge.json` 的 `lint_ignored_rules` 字段。

## 抠图

「抠图」页面用于配置抠图模型的权重、前处理参数与素材输出位置，同页下方的「贴图融合」组内是保存时的泊松融合开关（贴图的羽化、调色、投影已移除）。本程序不随包分发任何模型权重，只支持一个抠图模型：点「下载权重」可一键下到用户目录 `~/.labelforge/models/`，按钮下方那行会显示本次实际落点；也可以自己准备权重后填写路径。

### 抠图模型

| 项目 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 权重路径 | 文件路径 | 空 | 抠图模型的 ONNX 文件，通过「浏览...」选择；留空或文件不存在时，右键菜单中的「抠图素材」置灰 |
| 下载权重 | — | — | 从镜像 `hf-mirror.com` 下载官方 `onnx/model.onnx` 到 `~/.labelforge/models/rmbg14.onnx`（约 168 MB），下完校验大小与 sha256 通过才落盘；**点之前先看「权重路径」与默认位置，任一已有文件就只提示「权重已就位」，不重复下载、不覆盖** |
| 输入尺寸 | 0 ~ 8192（步进 32） | 0 | 0 显示为「按预设」，即 1024；换用其它导出（例如 512）时再填具体值 |
| 阈值 | 0 ~ 1（步进 0.05） | 0 | 0 保留模型输出的软 alpha；大于 0 时按该值把 alpha 二值化，边缘变为硬边 |
| 输出目录 | 目录路径 | 空 | 素材保存位置，留空表示写入 `<背景图目录>_matting_output/` |
| 基准测试 | — | — | 用当前权重与输入尺寸推理三次，取中位数耗时，结果显示在该按钮右侧 |

- 基准测试使用与输入尺寸同边长的纯色探针，不联网、不下载权重；未填权重路径时提示「未配置抠图模型」，权重或参数不可用时给出具体原因
- 基准测试耗时仅供参考，程序不据此自动切换模型，也不保存该结果
- 下载按钮下载的是本程序支持的那个抠图模型（权重为非商用许可），许可证说明见仓库根目录的 `THIRD-PARTY.md`；下载在后台线程里进行，关闭设置窗口会取消下载并删掉半截文件
- 权重一律下到用户目录，不放在程序目录：单文件 exe 运行时把自身解压到系统临时目录，进程退出即被清理，权重放在那里等于每次启动都要重下
- 以上设置保存在 `~/.labelforge.json` 的 `matte_model_path`、`matte_preset`、`matte_input_size`、`matte_threshold` 与 `matte_output_dir` 字段；输入尺寸的正值夹到 32 ~ 8192，旧配置里指向已删除预设的值在加载时归一到 `rmbg14`
- 点击「保存」后按新配置重建抠图模型；重建只校验参数与权重文件是否存在，真正加载权重发生在第一次推理

### 泊松融合

「贴图融合」组内只有「泊松融合」一个开关，默认关闭，保存在 `~/.labelforge.json` 的 `seamless_paste` 字段。贴图融合现在只剩这一项（羽化、调色、投影已移除）。

- 仅在保存合成图时生效，画布预览仍为普通叠加
- 旋转过的贴图项不参与泊松融合，该贴图按普通合成落笔
- 贴图贴近图片边缘、四周留不出蒙版之外的参考像素时，退回普通合成
- 混合失败（区域退化等）时保留已经完成的普通合成结果，不中断保存

## 恢复默认设置

设置对话框左下角的 **恢复默认设置** 按钮用于一键还原所有自定义配置：

- 删除配置文件 `~/.labelforge.json`
- 重置快捷键、主题、语言、界面参数（网格线、检测框、放大器、十字线等）
- 关闭「画布图片复制」「窗口放大器」「相对路径显示」等选项菜单开关
- 清空抠图配置（权重路径、输入尺寸、阈值、输出目录）并关闭「泊松融合」
- 清空记忆记录、裁剪参数模板与标签颜色映射
- 界面立即刷新为默认状态

> 操作前会弹出确认框，且不可撤销。如需保留当前配置，请先手动备份 `~/.labelforge.json`。

## 从旧版本升级

旧版本（1.5.3 及更早，项目名为 PasteLabel）的配置文件是 `~/.pastelabel.json`。

首次启动新版时，如果 `~/.labelforge.json` 不存在而 `~/.pastelabel.json` 存在，程序会
**自动把它复制**为 `~/.labelforge.json`，原有快捷键、主题、语言、参数、记忆记录与
裁剪模板全部保留。旧文件不会被删除。

用环境变量指定配置路径时不会触发该迁移：

- 新变量 `LABELFORGE_CONFIG_PATH`（优先）
- 旧变量 `PASTELABEL_CONFIG_PATH` 仍然识别

日志文件从 `~/pastelabel.log` 改为 `~/labelforge.log`，不做迁移。
