## 界面布局

LabelForge 界面分为四个区域：

1. **工具栏**（顶部）— 背景图/贴图/标签加载按钮，标注/贴图模式切换，记忆、选项、缓存、统计、质检、格式、导出按钮，以及最右侧的语言/主题/设置按钮
2. **画布区域**（左侧）— 显示背景图、贴图、检测框，支持缩放/平移/绘制
3. **控制面板**（右侧）— 背景图列表（步长翻页 + 工作/移除路径切换 + 任务/分组筛选）、标签列表、贴图列表、操作按钮
4. **状态栏**（底部）— 实时显示鼠标坐标/贴图数/检测框数/标签统计

---

## 1. 贴图/标注模式切换

工具栏右侧的双栏滑动切换控件，控制画布交互的优先级。**软件默认打开为标注模式。**

| | 标注模式（默认） | 贴图模式 |
|---|---|---|
| **悬停高亮** | 鼠标移到检测框上自动选中 | 鼠标移到贴图上自动选中 |
| **左键优先级** | 检测框 → 贴图项 → 背景 | 贴图项 → 检测框 → 背景 |
| **画布内放大预览** | 开启后，选中检测框或绘制时，鼠标位于背景图内自动显示 | 不显示 |

切换时状态栏显示 `Mode: Annotate` / `Mode: Paste`（2秒后消失）。

## 2. 背景图片管理

### 加载背景图片
- **单张加载**：点击「背景图」图标按钮，选择图片
- **批量加载**：点击文件夹图标，选择图片文件夹（自然排序）
- 加载数千张的大数据集时，列表会快速填充，标注状态图标随后逐行点亮，加载过程界面保持响应

### 切换背景图片
- 点击背景图列表中的图片
- 或使用快捷键：`D` 下一张、`A` 上一张
- 列表顶部的 **◀ / ▶ 箭头支持长按连切**：按住约 0.4 秒后开始连续翻页（约 8 张/秒），单击仍是翻一页
- **文件夹拖到画布/窗口**：直接按数据集加载该文件夹（替换当前列表，与文件夹按钮一致）；拖入单张图片则是追加
- **步长设置**：数字滚轮 1~9，每次翻页的图片数量

### 列表路径显示
- 默认显示完整绝对路径
- 在「选项」菜单最下方勾选 **相对路径显示**，改为显示相对路径（如 `images\1.png`），便于迁移数据集
- 以已加载文件夹的父目录为基准；跨盘符时自动回退为绝对路径
- 设置会写入配置文件，下次启动保持

### 复制图片路径（右键）
在背景图列表中**右键**任意一项，选择「复制图片路径」，即可把该图片的**全局绝对路径**复制到剪贴板。

> 无论「相对路径显示」是否开启，复制的都是完整绝对路径。

### 刷新背景图列表（文件夹被删的情况）
背景图列表的刷新按钮会重扫当前文件夹、就地增删列表项，不重新导入，也不丢未保存的标注。

如果**已加载的文件夹在运行期间被删掉**（或被拔了盘），刷新会**清空列表与画布**，并在状态栏提示「背景文件夹已不存在，已清空列表与画布」。从未加载过文件夹时提示「当前没有已加载的背景文件夹，无法刷新」，两者含义不同。

### 工作路径 / 移除路径
- 点击「工作路径」/「移除路径」按钮切换视图
- 工作路径：显示参与标注的图片，所有操作可用
- 移除路径：显示被移除的图片，右键仅可恢复，W/Q/Delete 快捷键禁用
- 移除路径为空时可安全切换，不会报错

### 标注状态筛选

点击背景图列表右侧的筛选按钮，在工作路径下循环切换筛选模式：

| 模式 | 图标 | 说明 |
|------|------|------|
| 全部 | 三色圆点 | 显示所有图片（默认） |
| 已标注 | 绿色实心圆 | 仅显示已有检测框的图片 |
| 未标注 | 灰色空心圆 | 仅显示没有 JSON 标注文件的图片 |
| 空标签 | 橙色中心点空心圆 | 仅显示有 JSON 但无检测框内容的图片 |

切换筛选时自动导航到首个可见图片。筛选仅在工作路径下生效，进入移除路径时自动隐藏筛选按钮。

> 标注状态按图片对应的 LabelMe JSON 文件判断：存在且有 shapes 为「已标注」，存在但为空 shapes 为「空标签」，不存在为「未标注」。

### 按任务 / 按分组筛选

背景图列表右侧除状态筛选外，还有两个筛选按钮（均为多选菜单）：

- **按任务筛选** — 按形状类型筛选，可勾选 `det` / `seg` / `pose` / `obb`，只看含对应形状的图片；菜单底部「全部」清空选择
- **按分组筛选** — 按当前图的 `group_id` 筛选，可勾选具体分组号或「未分组」；菜单底部「全部」清空选择

两者可叠加生效，勾选状态显示在按钮提示中。

### 刷新背景列表

在文件夹外新增或删除图片后，点击背景图列表右上角的 **刷新** 图标按钮，即可就地同步列表：

- 重新扫描**当前已加载的文件夹**（不弹文件夹选择框），按文件名自然排序比对
- 新增的图片追加到列表，已删除的图片从列表移除；其余项原地保留
- **不会**重新导入、**不会**丢失内存中未保存的检测框/画布项——它们按路径迁移到新索引
- 当前选中图优先按路径找回，找不到才回到列表首项
- 列表行只做轻量装饰（仅判断文件是否存在），类别集合与状态图标由后台扫描补齐，因此比重新选择文件夹快得多
- 结果在状态栏提示 2 秒：无变化显示「文件夹无变化」，有变化显示「新增 X 张 · 移除 Y 张」

> 尚未加载任何文件夹、或文件夹已不可读时，仅在状态栏提示，不弹对话框。

### 拖拽操作
- **拖入**：将图片（PNG/JPG/BMP/GIF）或 LabelMe JSON 拖入窗口，自动加载
- **拖出**：从画布按住左键拖到窗口外，复制当前背景图到桌面/文件夹（需开启「画布图片复制」）。**图没缩放时**拖图内就是拖出文件；**图放大过之后**拖图内是平移画布，要拖出请先按 Ctrl+0 之类恢复自适应缩放

## 3. 记忆

点击工具栏「记忆」按钮打开最近素材记录窗口。

### 自动记录
- 关闭软件时自动保存当前背景图路径 + 贴图路径 + 标签文件路径 + 图片索引
- 最多 10 组记录，按路径组合去重（同一组再次使用时更新到顶部）

### 操作
- **加载** — 清空当前素材后加载该组记录，自动跳到记录的图片序号
- **修改备注** — 按任务/数据集/客户名填写备注
- **删除** — 删除选中记录

## 4. 贴图功能

### 加载贴图
- **单张/批量**：点击「贴图」图标按钮，选择贴图文件
- **文件夹加载**：点击文件夹图标，选择贴图文件夹

### 手动贴图
1. 在贴图列表中点击贴图 → 自动放置到背景中心
2. 鼠标拖动调整位置
3. 滚轮缩放 或 拖拽右下角手柄调整大小

### 随机贴图
1. 设置参数：**贴图个数**（1~20）、**短边尺寸范围**（最小 15~100，最大 30~200）
2. 点击「随机贴图」— 中心点避让算法自动放置，避免与检测框/已贴图重叠

### 一键贴图（批量）
点击「一键贴图」，从当前图片开始逐张执行随机贴图，弹出进度条。

### 语义区域放置

在画布上绘制"语义区域"（矩形），随机贴图时贴图**完整落在**这些区域内，使合成样本符合画面语义（例如"车只贴在路面区域"）。

**入口**：

- **贴图模式**：画布**右键菜单**里有「添加区域（矩形）」「固定区域」「清空区域」三项
- **标注模式**：区域操作全部走「推理范围」面板（「添加区域」按钮 + 面板里的区域列表），画布右键菜单不提供区域项

**添加矩形区域**：
1. 贴图模式下右键画布空白处 → 菜单选择「添加区域（矩形）」；或点「推理范围」面板上的「添加区域」按钮
2. 左键**按下**定起点，拖动预览，**松开左键**完成

绘制中可按 `Esc` 取消。

**编辑区域**：贴图模式下**直接**可编辑（无需进入编辑模式）；「推理范围」面板开着时，标注模式下同样可以直接拖动/缩放区域
- 拖动区域内部：整体移动
- 拖动四角手柄：缩放、调整形状
- **鼠标悬停在区域上滚动滚轮**：绕中心缩放
- 均夹紧到图片边界，最小边长 10 像素

**固定区域**：画布右键菜单中的开关（贴图模式）。固定后所有区域锁定（不能拖动/缩放/滚轮/删除/新增/清空），但仍约束贴图落点。

**删除区域**：贴图模式下右键区域 → 删除区域；或右键空白处 → 清空区域（有二次确认）一次删全部。

**层级**：区域绘制在贴图**下方**（贴图会覆盖区域框）。

**外观**：青色虚线框，选中时加粗 + 淡填充 + 手柄圆点。

**跨图共享**：区域不随图片切换而清空，同一份区域对所有图片生效（关软件后消失，不保存到文件）。

**不持久化**：区域仅运行时存在，不写入 JSON、不导出、不影响标签。

**作用范围**：约束「随机贴图」「一键贴图」与**区域推理**；手动单张添加贴图不受约束。区域装不下贴图时该次贴图跳过。

**区域推理**：模型参数行的「推理范围」选「区域」时，只在这些区域内推理，区域外检出的框按框中心丢弃（详见「模型推理 → 推理范围」）。范围小窗开着时画布会画出区域轮廓；想加区域就点面板上的**「添加区域」**按钮，点一下在背景图上拖一次就画出一个，要再画一个就再点一次（不用先切到贴图模式）。面板开着时可以直接拖动/缩放区域框，**标签框也照常可以编辑**。切到别的范围模式或关掉小窗就撤掉画布上的轮廓提示。

### 贴图列表视图
- 缩略图视图（预览缩略图） ↔ 列表视图（显示文件名）

## 5. 标签管理

### 加载标签

工具栏「标签:」处有两个导入按钮：

| 按钮 | 图标 | 说明 |
|------|------|------|
| 背景标签导入 | 文件 + 下箭头 | 导入背景图标签文件，与扫描结果**取并集** |
| 贴图标签导入 | 文件 + 标签框 | 导入贴图标签文件 |

两者都读取文本文件（每行一个标签，也兼容 `类别 x y w h` 这类带额外列的行，只取第一列）。

**背景标签导入**的特点：

- 与从背景图 JSON 中扫描出的类别**取并集**，导入的类别不会被后续扫描覆盖，扫描出的类别也不会挤掉导入的类别
- 重复导入自动去重
- 文件为空时提示「未找到有效的标签」，读取失败时提示错误，均不改变现有类别
- 更换数据集或清空素材时，导入的类别一并清空

### 列表模式切换

背景图标签列表支持两种显示模式，点击标签列表标题行的模式切换按钮切换：

| 模式 | 说明 |
|------|------|
| 统计计数 | 按标签类别汇总显示数量，按数量降序排列（默认） |
| 每框一行 | 列出当前图片的每个检测框，每一行是一个框，显示标签名和位置信息，支持右键单独修改/删除 |

- 统计模式下右键修改/删除标签会级联操作所有使用该标签的检测框
- 每框一行模式下右键修改/删除仅影响选中的单个检测框

### 标签列表操作（右键）
两个标签列表都支持右键菜单：

| 操作 | 背景图标签 | 贴图标签 |
|------|-----------|---------|
| 增加标签 | 输入新名称，加入全局标签 | 输入新名称，加入贴图标签列表 |
| 修改标签 | 重命名，级联更新所有检测框 JSON | 重命名，级联更新所有使用该标签的贴图项 |
| 删除标签 | 删除，级联移除所有背景图中使用该标签的检测框 | 删除，级联移除使用该标签的贴图项 |

> 标签列表按数量降序排列，统计仅计算工作路径的图片。可通过列表标题行按钮在「统计计数」和「每框一行」两种模式间切换。
> 带有分组的形状在列表中显示为 `标签名 [分组号]`。

### 快捷键删除标签

按 `Ctrl+Shift+Z` 可直接删除，**不弹确认框**，适合连续清理标签。删除范围看你当前选了什么：

| 你选了什么 | 删什么 |
|------|------|
| **画布上选中了框** | 只删选中的那几个（框选多选就删那几个） |
| **标签列表选中了某一项** | 统计计数模式：删该标签在所有背景图中的全部检测框；每框一行模式：只删选中的那一个检测框 |
| **都没选**（焦点就在画布上） | 删掉**当前图全部**标签框 |

焦点在画布上即可删除，不必先在列表中选中条目。

> 右键菜单的「删除标签」仍会弹确认框，两者行为一致，只是快捷键跳过确认。快捷键可在设置中修改（位于「恢复图片」下方）。

### 自动添加标签
勾选「贴图标签」复选框后，添加贴图时自动从文件名提取标签（按 `_` 拆分取第一部分）。

## 6. 标注操作

LabelForge 支持四种标注形状，均以 LabelMe 格式保存到 JSON 的 `shapes` 字段：

| 形状 | `shape_type` | 快捷键 | 说明 |
|------|-------------|--------|------|
| 水平检测框 | `rectangle` | `W` | 常规轴对齐矩形框 |
| 分割多边形 | `polygon` | `P` | 逐点勾勒目标轮廓，用于分割任务 |
| 姿态关键点 | `point` | `K` | 单点标注，可配合分组组成姿态实例 |
| 旋转框 (OBB) | `rotation` | `O` | 可任意角度旋转的矩形框 |

> `shape_type` 缺省时按 `rectangle` 处理，兼容旧版 JSON。
> 所有标注共用同一套标签、分组和撤销/重做机制。

### 置信度

推理写出的每个形状带一个顶层 `score` 字段（0~1 的浮点数），手工绘制的形状写 `null` 占位。字段位置与顺序参考 X-AnyLabeling，`label` 之后紧跟 `score`：

```json
{
  "label": "car",
  "score": 0.9087275862693787,
  "points": [[10, 20], [110, 20], [110, 80], [10, 80]],
  "group_id": null,
  "description": "",
  "shape_type": "rectangle",
  "flags": {"inference": true}
}
```

置信度会随 JSON 保存并在重新载入后保留，可用「显示置信度」(Y) 在画布上显示为 `car 0.91`（保留两位小数，取值仍按原精度存储）。

### 画布内放大预览
开启「窗口放大器」后，标注模式下画布内显示鼠标附近的放大预览，辅助精准绘制与调整。放大倍率可在设置对话框中调节（0.8× ~ 3.0×）。

位置模式（设置 → 窗口放大器 → 位置）：
- **侧边（默认）** — 放大窗口在鼠标右下方偏移显示，仅选中检测框或绘制时激活
- **跟随鼠标** — 放大窗口以鼠标为中心显示，始终可见（无需选中框）

### 分组的用途

`group_id` 是一个整数分组标识，用于把多个形状关联为一个实例，典型场景是姿态关键点：一个人体框 + 若干关键点共用同一 `group_id`。所有形状类型均可选择性地填写分组号。

- 标签列表中有分组的项显示为 `标签名 [分组号]`
- 背景图列表可按任务、按分组筛选
- YOLO 姿态导出按 `group_id` 组合人体框与关键点

### 绘制检测框（水平框）

1. 点击「绘制 BOX(W)」或按 `W` 键进入绘制模式
2. 在背景图上按住鼠标左键拖动
3. 释放鼠标完成绘制
4. 弹出标签选择对话框，选择/输入标签，可填写分组号

> 检测框最小 3×3 像素。

### 绘制分割多边形

1. 按 `P` 进入多边形绘制模式
2. 依次**左键单击**添加顶点（最多 32 个），鼠标移动显示临时连线
3. 完成绘制（任选其一）：
   - **双击**最后一个顶点
   - 按 `Enter`
   - 在画布上**右键**

### 标签统计

点击工具栏「统计」按钮打开标签统计弹窗。**背景图标签**与**贴图标签**合并到同一个位置，用标签页切换（位于窗口左侧）：

> 弹窗**先出来、再统计**：打开时表格先空着、底部提示「正在统计…」，扫完数据集自动填入。

- **背景图标签** — 显示类别名称、数量、框类型、颜色，按数量降序
- **贴图标签** — 显示贴图类别和数量，统计**整个数据集**（磁盘已保存的贴图 + 当前会话未保存的贴图；同一位置以内存为准）
- **颜色替换** — 点击颜色按钮可替换类别颜色，按钮显示当前 HTML色值并立即更新

**数据集健康**（同一弹窗右侧）：

打开标签统计时后台扫描数据集，展示 4 个诊断面板并给出文字建议。**切换标签页即切换数据源**：切到「背景图标签」查看标注分布，切到「贴图标签」查看贴图分布——当前数据源显示在健康区顶部，切换即时生效（无需重新扫描）。

**面板可拖拽/拉伸**：4 个统计面板是独立组件，拖动面板标题栏可与相邻面板交换位置，拖动面板之间的分隔条可调整大小，相邻面板自动让位；图表随面板高度自动伸展。面板不会被关闭。默认左侧表格区 : 右侧图表区 ≈ 1:2，同一行的面板默认 1:1，重排为单列时自动 1:1 等高，打开窗口时自动应用。

每个面板含标题、说明文字与图表：

- **类别分布** — 各类别框数量条形图，使用类别自身颜色，柱旁显示数量与占比，标出最多/最少类别
- **尺寸分布** — 框面积（宽×高，像素面积 px²）直方图，观察尺寸长尾；左上角「框数」为该图统计的框总数
- **长宽比分布** — 框长宽比（w/h）直方图，观察形状多样性
- **IoU 重叠分布** — 同类框两两 IoU 直方图，观察重复/密集程度；纵轴是**同类框配对数**（不是框数），单图框数 > 500 时跳过该图

> 贴图统计依赖保存时写入的 `flags.paste` 标记。历史版本保存的 JSON 没有该标记，其中的贴图无法从磁盘识别，仅能统计当前会话内存中的贴图。

底部「建议」根据当前数据源统计自动生成，例如「类别 X 样本偏少，建议多合成」「长宽比单一，多样性不足」等。仅诊断，不写盘、不改标注。

表格左上角角按钮颜色跟随深色/浅色主题。

### 标注质检

点击工具栏「质检」按钮，后台扫描当前数据集并弹出「标注质检」结果窗口（非模态，可边看边改）。

**扫描内容**（仅报告，不自动修改）：

| 问题类型 | 判定 |
|---------|------|
| 越界框 | 框（bbox）超出图片边界 > 1px |
| 小目标不可检出 | 框短边 / 图长边 < 0.625%（≈4px @ 640 等比输入），常规配置基本检不到 |
| 小目标需放大 | 比例 < 1.25%（≈8px @ 640），需 P2 检测头或裁剪放大才稳 |
| 重复框 | 同类框 IoU ≥ 0.85 |
| 异类重叠 | 不同类框 IoU ≥ 0.85 |
| 近似名 | 标签名仅大小写 / 空格差异 |
| 分组不一致 | 关键点无同组框 / 不在框内，或有组框无关键点 |
| 跳过两两比对 | 单图框数 > 500 时跳过重复/重叠比对，仅提示 |

> 缺 sidecar 文件与空标注不上报（背景图列表状态图标已覆盖）。
> 尺寸类检查（小目标两档）只看矩形框，含贴图、跳过关键点与多边形；
> 判据是**把原图与框等比缩放（长边→640、短边补边）到模型输入后，框短边还剩几像素**：
> 比例 = `min(框宽, 框高) / max(图宽, 图高)`，三档线就是 4px / 8px / 16px @640。
> 分母取**图的长边**。该口径与训练分辨率无关：480×480 上的
> 6px 框缩放到 640 后是 8px（通过），1920×1080 上的 8px 框缩放到 640 后只剩 2.7px（不可检出）。
> 带 `flags.tiny_keep` 的框视为有意保留，尺寸检查不再上报（不计入表格，仍计入报告的「已豁免」）。

**结果窗口**：

- 顶部显示各类型问题计数与扫描图片数
- 表格按**背景图分组排序**（同图问题相邻，同图内按类型、类别名），可下拉筛选问题类型
- 表格第 4 列「尺寸/提示」：小目标两档显示「宽/高 + 占比 + 建议」（如 `宽不足 0.45% · 常规配置检不到，建议提高分辨率或滑窗切片`；宽高都不达标时显示 `宽高均不足`），其余类型沿用问题描述；列宽不够时悬停可看全文
- **双击**某行 → 跳转到对应图片并选中问题框
- 当前图问题清空后，**自动跳到下一张**仍有问题的图（末尾回绕）

**右键菜单**：

- **标记保留 / 标记保留选中的 {n} 项**（仅小目标两档）— 给问题框写入 `flags.tiny_keep`（内存与 sidecar 同步），此后该框不再触发尺寸类问题，报告计数转入「已豁免」
- **忽略此项 / 忽略此类问题** — 记入配置，后续扫描不再显示；可在「设置 → 质检忽略」页查看 / 移除
- **删除 '{类别}' 框**（仅异类重叠）— 外科式删除选中问题里该类别的重叠框（后台执行、内存与磁盘一致、可中断）；此操作**不可撤销**，会弹确认框

**实时刷新**：删除 / 重命名标签、删除标签文件、撤销 / 重做后，当前图问题自动增量重扫（去抖 250ms），无需重新扫描整个数据集。

### 模型推理

工具栏「模型推理:」后面有三个图标：**显示参数行**、**推理当前图片**、**从当前图片推理到末尾**。

**参数行是唯一的模型入口**：第一个图标负责显示/隐藏画布上方的参数行，加载模型按钮也在这一行里。没加载模型时两个推理图标是灰的；**点参数行的 × 关掉它之后同样不能推理**（推理图标变灰），模型本身仍然保留，再点第一个图标打开就能继续用。阈值和尺寸都在这一行里随时调，**改完立即生效，不用重新加载模型**。

**贴图模式下不推理**：切到贴图模式时参数行会**自动收起**、两个推理图标随之变灰。切回标注模式会自动恢复；参数行本来就是收起状态时，切回来也不会被强行展开。

**加载模型**

点参数行里的「加载模型」选一个 `.onnx` 文件。支持 YOLOv5 / YOLOv8 / YOLO11 / YOLO26 的**检测**导出（分割、姿态、OBB 暂不支持）。类别名按以下顺序取：

1. 模型同级同名 `.txt`（`yolov8n.onnx` → `yolov8n.txt`），一行一个类别
2. 模型自带元数据里的 `names`

两者都没有时会弹出输入框让你手填，填完会写成同级同名 `.txt`，下次直接复用。**取消输入等于不加载模型**，两个推理图标保持灰色。

输出格式默认自动识别（按输出形状判断），识别不唯一或遇到不支持的导出方式时会明确报错，不会猜。

| 模型 | 输出形状 | 处理方式 |
|------|----------|----------|
| YOLOv5 | `[1, N, 5+C]` | 置信度 = objectness × 类别分数，再做 NMS |
| YOLOv8 / YOLO11 | `[1, 4+C, N]` | 置信度取类别分数，再做 NMS |
| YOLO26 | `[1, N, 6]` | 端到端导出，`x1,y1,x2,y2,score,cls`，**已内置 NMS，不再去重** |

YOLO11 与 YOLOv8 输出结构完全一致。

YOLO26 这类端到端模型导出时已做完 NMS，本软件**不会**再跑一遍，以保证与官方结果一致；参数行里的 NMS 输入框会置灰并标注「该模型已内置 NMS，此项不生效」。已知这类输出中可能仍有同类高 IoU 的重叠框（属模型自身 NMS 阈值偏松），需要更干净的结果时请提高置信度。

**参数行内容**

各功能之间用 `-` 隔开，分成七组：`加载模型`+模型名 · `conf`+`NMS` · `输入尺寸` · `覆盖/补充` · `类别筛选` · `推理范围`+摘要 · `目标张号`。其中「输入尺寸」收起时分隔符会顺带少一条。

| 项 | 说明 |
|----|------|
| 模型名 | 当前模型文件名，悬停可看输入尺寸与生效设备 |
| conf | 置信度阈值，标签就写作 `conf`（中英界面都一样）。默认 0.25；YOLOv5 为 objectness × 类别分数。步长 0.01，可逐点点微调 |
| NMS | 按类别 NMS 的 IoU 阈值，默认 0.45；端到端模型（YOLO26）此项禁用。步长 0.01 |
| 输入尺寸 | **只有动态轴模型才显示**；静态轴模型的尺寸由模型自身决定，这一组（标签与两个输入框）直接**收起**，不占位置也不给改。未加载模型时同样收起。收起时它左侧的那条 `-` 也一起收掉 |
| 覆盖 / 补充 | **默认覆盖**（每次启动都回到覆盖，不记忆上次选择）：先把这一图的检测框**全部清掉**（含手画的），再写入本轮结果；切到补充则在已有框上追加。**贴图两种模式下都保留**——它单独存 json，不属于检测框 |
| 类别筛选 | 默认全选（等于不过滤）；取消勾选的类别之后，只保留勾选的那些。按钮上显示 `(已选/总数)`。启用筛选后会连带清掉上一轮推理里不在勾选范围的框（人工标注与贴图不受影响），所以筛选结果与勾选严格一致；一个都不勾就什么都不保留 |
| 推理范围 | 默认全图；可选滑窗 / 区域，详见下一节。按钮**右侧**常驻显示当前模式（`全图` / `滑窗` / `区域`）。面板里**改了立刻生效**，没有「确定 / 取消」 |
| 目标张号 | 在「推理范围」右侧的输入框，前缀就写着「目标张号」：填的是**结束那张图是第几张**（1 基、含），配合「一键推理」用。**默认值是当前数据集的最后一张**（换数据集会自动跟着变），所以默认就是「跑到末尾」。当前停在第 200 张时填 300 就是跑 200~300，填 100 就是跑 100~200（往回跑也行，方向自动判断）。**你改过之后就不会再被默认值覆盖**；留 0 或清空 = 不限制，一直跑到列表末尾。上限自动跟着当前数据集的张数走 |
| × | 关闭参数行（关闭期间不能推理）；模型保留，再点第一个图标恢复 |

**输入尺寸会记进配置**，下次启动加载模型时自动沿用（动态轴模型不必每次重填）。滑窗的窗口尺寸与重叠也会记住（`window_spec`）。**置信度、NMS 与推理范围不记忆**：前两者每次启动都回到默认（0.25 / 0.45），后者回到全图。

**执行范围**

- **推理当前图片**：只处理当前显示的那张
- **一键推理**：从当前这张顺序往下跑，跑到「张数范围」指定的目标张号为止（不填则到列表末尾），弹出可取消的进度小窗
- 换数据集后迟到的结果会被丢弃，不会写到另一批图片上

**进度小窗**：显示总进度条与最近 5 条记录，每条带北京时间（固定 UTC+8，不跟随本机时区，精确到毫秒，只给时刻不给年月日）、文件名、该图检出的框数与单张耗时（毫秒）。最新记录在最上面；**向上翻看历史时新结果不会把视图拽回顶部**。标题栏上方汇总累计检出框数，点 × 即取消（已完成的结果保留）。

**结果写入**

- 推理结果以 `flags.inference` 记录来源，不会被当成贴图
- 当前显示图一次性替换标注：只保存一次撤销快照（`Ctrl+Z` 可整批撤销）、刷新一次列表、写一次 sidecar
- 其余图片直接写各自 sidecar，保留原有的 `version`/`flags`/贴图/多边形等字段
- 单张失败只记录该图，不中断整批；取消后已完成的结果仍然保留
- **覆盖模式会把这一图的检测框全部清掉**（手画的也清），只留本轮结果；贴图不受影响（它单独存 json）
- **取消后当场刷新**：跑到一半点取消，已经跑完的那几张**立刻**变成已标注圆点，画布上的框也会同步（不必切到那张图才更新）

**没检出的图不写盘**：没有检出结果、合并后也没有任何标注的图片不会生成 json，原本就是空 `shapes` 的 json 会一并删掉，避免数据集里堆满空文件。**贴图**（`flags.paste`）算标注，有贴图的图照常写回，不会因为「这次没检出」而丢失。

覆盖模式下这一轮没检出、把上一轮推理框清空时，磁盘上那份旧 json 会先被改写成空、再删掉，图标的圆点**当场**更新，不需要切图。

运行期间换数据集（或视频抽帧后重新加载）后，已加载的模型仍可继续对当前数据集推理并正常落盘。

**坐标与通道约定**：模型输入为 RGB、NCHW、0–1 浮点；等比缩放后居中补边（填充 114），结果按同一组整数逆变换回原图坐标并钳到图内，落在补边区里的框直接丢弃。

**已验证的模型**：`yolov5n.onnx`（`[1, 25200, 85]`）、`yolov8n.onnx`（`[1, 84, 8400]`）、`yolo11s.onnx`（`[1, 84, 8400]`）、`yolo26s.onnx`（`[1, 300, 6]`，端到端），均为 ultralytics COCO 80 类导出，静态 640×640 输入，类别表自动读自模型元数据 `names`。分割、姿态、OBB 导出暂不支持；动态轴模型需在模型行里指定输入尺寸。

**非官方导出（模型没有类别信息）**：加载时会弹出多行输入框，一行一个类别名；填写后保存到模型同级的同名 `txt`（如 `nonmotor.onnx` → `nonmotor.txt`），下次加载直接复用。能从头一个输出形状推出来的话，输入框会提示「模型需要 N 个类别」，填的个数不一致时会当场标出「数量不一致，请核对」，但不阻止保存——以你填的为准。取消输入则该模型不能推理。

**带辅助输出的第三方导出**：不少 YOLOv5 训练导出的模型除了主检测头，还会额外挂出每个 stride 的原始头（形状是 5 维的 `[1, 每格锚数, H, W, 5+C]`，数值还没解码）。这类模型按输出个数看是"多输出"，但检测头只有一个，工具会自动挑出那个 3 维输出继续推理，忽略其余辅助头，类别数提示也照样能给出。判别只看形状、不看输出名（第三方导出的名字毫无规律）：3 维输出恰好一个就用它；一个都没有（分割 / 姿态 / OBB 导出）或有多个而说不清哪个是检测头时，会报错并列出实际输出形状，不会瞎挑一个来用。

**没有类别表的模型怎么定格式**：模型的 `metadata` 里带 `names` 时以它为准；没有（第三方导出常见）就看检测头两个轴的长短——通道轴是 `5+C`（v5）或 `4+C`（v8），解出的 C 落在 1~80 且另一轴够大时才认。所以 `[1, 25200, 9]`（4 类 v5）和 `[1, 84, 8400]`（80 类 v8）都能自动判出来，不必手动选格式。推不出唯一解释时（如两个轴都能解释成通道、或类别数超过 80）会明确提示手动选择格式，不会猜一个来用。

**推理范围：全图 / 滑窗 / 区域**

点参数行里的「推理范围」按钮选范围。默认全图（一次推理整张图），其余两种用于大图或只看局部。**按钮右侧常驻显示当前模式**：

| 范围 | 说明 |
|------|------|
| 全图 | 整张图推理一次 |
| 滑窗 | 按你设的窗口尺寸切分后逐窗推理，结果合并回原图并去重 |
| 区域 | 只在画布上画好的区域内推理（用面板上的「添加区域」按钮在背景图上画） |

**改了立刻生效**：面板是实时的，没有「确定 / 取消」按钮——切模式、改窗口参数，改的那一刻就写进摘要、就用于下次推理。**关掉面板（右上角 X）不会回滚**，关掉只是因为调完了；想撤销就再改回去。

**滑窗参数随时可见、按段可改**：范围弹窗分成**三段**——「全图」「滑窗」「区域」各占一个分组框，**各自的内容始终显示**（滑窗的窗口参数、区域的条数与明细都看得见），不必来回切换模式核对。只有**选中的那一段**能改，其余两段的内容置灰（看得到当前值，点不动也改不了）；每段的模式按钮本身始终可点，方便随时切换。

滑窗段里有窗口宽高（默认 640×640，下限 8）、重叠像素（默认 200）与**最低可见比例**（默认 80%，可调 50%~100%）。窗口尺寸与模型输入尺寸**互相独立**：窗口是原图上的裁剪范围，模型输入仍由模型行里的「输入尺寸」决定。面板实时显示「每张图 行 × 列 = 个窗口」，3840×2160 配 640×640、重叠 200 是 5 × 9 = 45 窗。窗口数超过 20000 时面板会直接提示参数非法；重叠给得比窗口还大不会报错，会被静默收到「窗口尺寸 − 1」。

**最低可见比例**：窗口切分后，模型可能把窗口边界上的目标检成一个「只露一角」的框，这种框在相邻窗会各出一份，既容易重复又容易留下半个目标。跨窗合并去重**之前**，可见比例低于这个值的框会先被丢掉（默认 80%，最低 50%）。调低会保留更多边缘框，调高会更干净但可能丢掉贴着切缝的目标。这一项**只影响滑窗模式**，全图与区域不受影响。

**参数旁边就是原图叠加的窗口网格**：改宽、高或重叠，网格立刻在原图上重画，可直接看出窗口落在画面哪一部分。

**范围弹窗不挡画布**：它是非模态的，开着时仍可点击画布、拖动画区域。它固定浮在**右侧侧栏「标签管理」区的正上方、左上角与那块对齐**（竖直方向也跟着），不压住左边的画布。窗口贴到屏幕边缘时，弹窗会自动收进屏幕内。

**区域规则**：

- 区域沿用画布上已有的临时区域（矩形），**不持久化**，程序重启后范围回到全图
- **画区域要点按钮**：面板上有个「添加区域」按钮，**点一下画一个**——点完之后在背景图上拖一次就落成一个区域，画完自动退出绘制态，要再画就再点一次。区域内编辑**不进撤销栈**
- **贴图区域与推理区域是两份**：贴图模式右键菜单画的区域约束贴图落点；标注模式下用面板「添加区域」画的区域用于区域推理，两者互不影响
- **面板开着时可以直接调整区域框的大小和位置**：拖动区域内部整体移动，拖手柄改大小（平时区域只在贴图模式下可编辑，面板开着时放开）。**关掉面板后**，标注模式下点区域框不会动它
- **面板开着时标签框照常可以编辑**：能选中、能拖动、也能画新的。调区域时如果怕误改标注，用下面那条「逐条锁定」把区域锁上，而不是靠关掉面板
- **面板里逐条列出已画的区域**：`#N (x, y) 宽×高`，每条右侧有「锁定 / 解锁」与「删除」两个按钮。删除点掉哪条就删画布上对应的那条，不用回画布上右键
- **每条区域可以单独锁定**，锁定的区域落到**检测框下层**且**不能修改**（点它会穿透到底下的框）；不锁的（默认）在**检测框上层**，和检测框一样可以拖动/缩放。重叠处点击归**未锁定**的区域——想让底下的框能点到，就把区域锁上。锁定只影响画布上的编辑与层级，**区域照常参与推理**
- 矩形区域直接把区域内的像素喂给模型
- **只保留框中心落在区域内的结果**（含边界），区域外检出的框会被丢弃
- **多个区域重叠时会自动去重**：区域各裁各的，重叠那块会被推理两遍，同一个目标就出两份；合并时按类别做 NMS 去掉重复（用模型行里的 NMS 阈值），不同类别的框始终都保留
- 区域坐标按**当前显示图**的尺寸记录；批量推理时尺寸不一致的图片会单独报失败并保留其原有标注，不会把区域缩放到别的图上
- 选了区域范围却没画区域时，面板会提示「没有可用区域，请先画好区域」——避免「成功但 0 框」把原有自动标注删掉

**画布上的范围提示**：范围小窗开着时，滑窗画出窗口网格、区域画出区域轮廓。**两者互斥**——选了滑窗只看得到网格，选了区域只看得到区域框。**关掉小窗提示立即消失**，不会继续叠在画布上；区域内容本身保留到本次运行结束（重启失效）。

**滑窗网格标着行列号**：每个窗口的**左下角**标出 `r1c1`（第 1 行第 1 列），编号与数据增强预览同源（行优先、从 1 起）。格子太小（小于 44×30 像素）或同时可见的格子太多时不标行列号。

**区域框可以拖、也可以改大小**：鼠标悬在区域内部拖动 = 整体移动；拖**四个角** = 同时改两个方向；鼠标压在**边上**拖动或**滚轮** = 只改那一条边（单边调整）。手柄的命中范围与绘制大小随缩放调整（图很小时手柄会自动变大）。**锁定的区域不能这样改**，它会滑到检测框下层。

**滑窗与数据增强共用同一套排布**：窗口起点复用数据增强裁剪的那份窗口数学，且推理侧**一律贴边不补边**（末窗正好落在图像边界），不像数据增强的「填充」模式那样让窗口越出图像再补填充色。

**合并去重**：跨窗口/跨区域检出的同一目标按类别做 NMS（用模型行里的 NMS 阈值）。滑窗模式会先用「最低可见比例」丢掉只露一角的框，再做 NMS。注意**重叠很大的滑窗可能残留少量低 IoU 重复框**，这是标准贪心 NMS 的固有行为；需要更干净的结果时减小重叠、提高 NMS 阈值或提高最低可见比例。不同类别的高重合框一定都保留。

**结果为空也是结果**：某张图被覆盖模式清成 0 框之后，它就是一个**真正的空结果**。切回那张图不会再把之前的旧框读回来——「没加载过」与「加载过、结果为空」是两件事，后者不会被磁盘上的旧 JSON 顶替。

**覆盖与区域**：默认覆盖模式下，区域推理会把该图**所有**检测框清掉（包括区域之外的和手画的）。界面会在状态栏提示这一点；想保留旧框请切到补充模式。贴图不受影响。

**耗时**：范围推理要跑多个窗口，单张耗时约为全图的窗口数倍；批量任务的进度小窗仍按**每张图**记录一次，不按窗口。


### 视频抽帧

点工具栏「视频:」后面的胶片按钮，打开配置窗口。窗口里有三个标签页：

**抽帧页**：选视频、填每秒抽几帧与时间段（留默认即全片），点「开始抽帧」导出等比时间间隔的图片。选好视频后会立刻显示分辨率/帧率/帧数/时长，并把帧率上限设为源帧率（抽帧不重复源帧）。输出目录固定在视频同级、自动创建（重名时用 `_frames_2/`、`_frames_3/` 递增），窗口里只读展示，不能改到别处。

**合成页**：选一个图片目录，程序自动判断里面有没有 `video_manifest.json`：

- **有清单**（就是抽帧产出的目录）：按清单的顺序与时长合成，「每秒几帧」自动禁用——时长以清单为准，输出帧率 = 张数 / 清单时长。
- **没有清单**（外部拿来的图片序列）：按你填的「每秒几帧」合成，时长 = 张数 / 帧率。图片按名称自然排序（`img2` 在 `img10` 之前）。

输出视频写在图片目录同级、`<目录名>.mp4`（重名加序号），只读展示。合成完成会提示输出文件位置，不会把视频当成图片数据集加载。

**叠加标签框**（合成页，可选）：勾上「叠加标签框」，就会把每张图各自的标注框画到画面上，做成"带标注预览"的视频。

- **类别**：列表自动扫出这批图里出现过的类别（后面括号是出现次数），逐个勾选要画哪些。默认全勾上。
- **类别名**：在框上方画一条色条写类别名，默认勾上——和画布上的「显示Label」一致。
- **置信度**：把分数写进色条，默认勾上——和画布上的「显示置信度」一致。两个开关互相独立，可以只留一个。
- 框的颜色、线宽、字号与编辑器一致（同一类别颜色相同，线宽与字号随画面分辨率缩放）。
- **没标注的图不会被丢掉**：照样按原画面写进视频，合成完成后会提示有多少张没标注。
- 目录里**一个标注文件都没有**时，「叠加标签框」置灰不能用；标注文件**存在但读不出来**（损坏、结构不对）会直接报错，不会静默当成"没有标注"。不勾这个开关时，合成完全不读标注文件。
- 抽帧页导出的图片如果还没标过框，这里就是干净画面。

- **按时间采样，不按固定帧步长整除**：采样时刻按 `start + k/目标帧率` 计算，再映射到最近的源帧。60 秒、30 FPS 按 2 FPS 抽得 120 张。
- **目标帧率高于源帧率会被钳到源帧率**（不重复输出同一帧），实际使用的值记在清单里。
- **末点剔除**：采样时刻 ≥ 结束时间的丢弃，避免多出 1 张。
- 每张图配一条映射记录，写在 `<输出目录>/video_manifest.json`：`source_frame` 是绝对源帧号（从 0 起），`timestamp = source_frame / 源帧率` 是实际源帧时间，`sample_time` 是计划采样时刻——两者不能混（29.97 FPS 第 15 帧约 0.5005 秒，不是恰好 0.5 秒）。
- **取消 / 视频损坏 / 抽帧中途失败**：已抽出的图片保留，清单标 `complete: false`，不把半成品当成功。抽完的目录可以直接当数据集加载。
- 中文路径正常。
- 未安装 opencv 时工具栏「视频:」后面的胶片按钮置灰并说明原因；图片推理与滑窗功能不受影响。

**推理成片页**：选一个视频，程序**逐帧跑模型**、把检出的框画在每一帧上，再编码成一段新视频，用来直观检查模型在整段视频上的表现。

- 与「合成页」的叠加框不同：合成页画的是**已有标注**，本页画的是**现场推理的结果**，源视频不需要有任何标注。
- 输出与源**同帧数、同分辨率、同帧率、同总时长**；内嵌编码器固定为 mp4v（`.mp4`）。
- 框的样式（类别色、类别名、置信度、线宽、字号）与画布、合成页一致，同一类别颜色相同；线宽与字号随画面分辨率缩放。
- 输出写在源视频同级，命名 `<源文件主名>_render.mp4`（重名时递增为 `<源文件主名>_render_2.mp4`、`_3`），路径只读展示，不会覆盖别人的文件。
- **分辨率上限与推理范围**：本页用当前加载的模型，遵循参数行的**推理范围**（全图 / 滑窗 / 区域）。范围按**源视频首帧尺寸**校验，尺寸对不上会在开始前报错。
- **不接受奇数宽高的源**：mp4v 会把奇数尺寸**静默截边**（65×49 编码出来是 64×48），遇到奇数尺寸会明确报错。
- **完成前逐帧回读验收**：编码结束后会把产物整段解码一遍，核对帧数、尺寸、帧率、时长，**全对才发布到正式文件名**，否则按失败处理。
- **取消 / 中途失败**：
  - 取消时**已完成的部分会保留**成可播放的半成品（输出目录里的 `.<输出文件名>.partial.mp4`，隐藏文件），并提示已完成多少帧、正式输出未生成。半成品只留能**真正解码出帧且尺寸正确**的（零帧的空文件头会被清掉）。
  - 失败（编码器打不开、尺寸被截、回读帧数不符）不会生成正式文件；原有的输出与源视频原样保留。
- 可变帧率的源按平均帧率当作恒定帧率处理。
- 中文路径正常。没加载模型时本页说明原因、不能开始。

## 10. 数据处理

### 10.1 数据增强

对数据集图片进行批量变换，同步生成增强后的图片与 JSON 标注。

| 参数 | 说明 |
|------|------|
| 变换种类 | 支持 12 种变换：水平翻转、垂直翻转、亮度、对比度、色相(H)、饱和度(S)、明度(V)、高斯噪声、椒盐噪声、随机平移、随机旋转、随机缩放，每种可独立勾选启用，部分变换配有参数范围（最小 ~ 最大） |
| 滑窗裁剪 | 勾选后把高分辨率图按固定尺寸切为多个带重叠的子图（默认按首图反推出 **2 行 × 3 列** 的网格，重叠默认为窗口的 **15%**），跨窗标注按最小可见比例（默认 70%，低于丢弃；可调范围 50%~100%）过滤，空窗不落盘；点「配置…」打开参数小窗（锁定联动、边缘填充、模板、实时预览），详见下方「滑窗裁剪参数小窗」；输出 `{原名}_crop_r{行}c{列}_ov{重叠值}` 子图与 JSON，开启边缘填充时追加 `_pad` |
| 原图 | 可选是否将原图一并写入增强结果 |
| 图片比例 | 0.05 ~ 1.0，控制增强图片数量相对原图的比例 |
| 模式 | **全部增强** — 对所有图片应用所有已选中的变换；**随机几项** — 每次随机选取部分变换组合 |

增强结果保存至 `exports/images/`，图片与对应 JSON 标注同步增强。支持操作中断和清空输出。

#### 滑窗裁剪参数小窗

布局为**上中下三段**：顶部参数区按三列并排（尺寸/重叠/数量 · 可见比例/边缘填充/预览图 · 模板），中部是占满宽度的实时预览，底部是红绿图例与「确定 / 取消」。预览把各窗口拆成分离小图并排展示且均显示图像内容，**绿框=保留，红框=空窗丢弃**；摘要行给出「共 N 图 · 预计产出 M 张」。

**三组量的联动**

窗口尺寸（宽/高）、重叠长度、裁剪数量（按**行 × 列**显示）三者满足 `n × 尺寸 − (n−1) × 重叠 ≥ 边长`。**宽高是自变量**：你想切成多大就设多大，另外两项按下面的规则跟上。

- **未开边缘填充**：宽高与重叠**互相反推**。改宽高 → 反推出一个让该轴恰好铺满的重叠，另一轴再按这个重叠取到也恰好铺满的尺寸；改重叠 → 两轴尺寸一起反推。于是网格**始终恰好铺满**整幅图，末行末列窗口都贴边，不多切也不少切。改数量则保持当前重叠反推尺寸。
  - 恰好铺满要求 `n × 尺寸 − (n−1) × 重叠 = 边长` 有整数解。宽轴能解时优先由宽轴驱动，另一轴由该重叠反推；某轴无整数解时该轴保持不动（不硬凑），摘要行会显示实际行列数。
  - 由于重叠两轴共用一个像素值，两轴未必都能同时精确铺满；能解的那轴精确铺满，另一轴取到能排出该数量的最小窗口（末窗仍贴边）。
- **开启边缘填充**：**不反推**。宽高就是你设的值，不够的部分由填充补上，重叠保持不动。等步长落位下两轴不可能都精确铺满，所以此时不追求同步，差多少补多少。
  - 补边不得超窗口的 30%，超限时**只动重叠、不动你设的宽高**（详见下方「补边上限 30%」）。
- 另有「正方形」勾选可锁定宽高相等。

**补边上限 30%**

开启边缘填充后，补边量**不得超过窗口宽/高的 30%**。这是**硬约束**：任何入口（手动输入、改重叠、改数量、套模板、换图、打开小窗）都不会让超限值留在界面上。

- 上限对**每一轴**独立生效：宽轴补边 ≤ 窗口宽的 30%，高轴同理；重叠两轴共用一个值，故须**同时**满足两轴。
- **超限值吸附**：当前组合超限时，改的是**重叠**（宽高是你设的自变量，不动），吸附到最近的两轴同时合规值；距离相同时取较小值。确实吸附过时，摘要行给出 ⚠ 提示，调到合规值后提示自动消失。
- **硬墙**：宽高与重叠的输入范围会被钳到「当前值所在的那一段合规区间」，用鼠标/键盘都拖不出超限值。合规集合在固定重叠下是**锯齿状多段**（窗口数每变一次补边就跳回 0，例如 600 图上重叠 60 时有 15 段），所以墙按「当前所在段」设置，而不是只钳最外端。
- 重叠的合规段还会**叠加「半窗」上限**（未锁数量时），两个上限同时生效。
- 锁定「重叠 + 数量」时：尺寸可行区间直接排除补边超限的组合，区间会比不开填充时更窄；关掉填充后区间立刻恢复原状。

**默认值**

首次配置（尚无已保存参数）时，按当前首图尺寸反推出恰好 **2 行 × 3 列** 的窗口尺寸，重叠取窗口的 **15%**。重叠两轴共用一个像素值，无法在两轴上都恰好等于 15%，故以**较小窗口边**为基准。换用不同尺寸的数据集后，默认值会跟着重算，网格始终保持 2×3；尚未加载数据集时按 640×640 名义尺寸计算。

**锁（每组量右侧的 🔒 图标按钮）**

- 🔓 点击上锁、🔒 点击解锁；锁定的量成为约束，联动时**永不被自动改动**，未锁的量按锁定项反推。
- 最多同时锁 **2** 组；锁第 3 组时自动解开**最早锁的那一组**（按点击先后轮转）。
- 锁满 2 组后，第三项**并非唯一确定**，而是一段**可行区间**：
  - 锁「重叠 + 数量」→ 尺寸可编辑，输入范围自动收窄到所有能排出该数量的尺寸（例：1920 图上锁 3 列、重叠 88，尺寸可在 699~1003 之间自由调，列数始终是 3）
  - 锁「尺寸 + 数量」→ 重叠同理可编辑，范围取宽高两轴可行区间的**交集**（重叠两轴共用一个值）
  - 锁「尺寸 + 重叠」→ 数量是纯结果、没有自由度，输入框才置灰只读
- 解锁后输入范围立即恢复原状（尺寸 8~8192、重叠回到半窗口径）。
- 常见用法：锁「数量」+ 锁「重叠」→ 尺寸在可行区间内自由挑；锁「尺寸」+ 锁「重叠」→ 数量自动算出。
- 锁定「数量」时，重叠上限从「半窗」放宽到「窗口 − 1」。
- 若当前尺寸/重叠凑不出锁定的数量，会按最接近的可行值调整，并在摘要行给出 ⚠ 提示。
- 锁定状态是临时的：不写入模板、不跨会话保留。

**边缘填充**

- **关闭（默认）**：窗口尺寸被压缩到不超过图像，末行/末列窗口贴边排布，不越界。
- **开启**：窗口尺寸**严格固定**，按等步长（步长 = 尺寸 − 重叠）排布；末行/末列窗口可越出图像右/下边缘，越界部分用右侧 RGB 颜色补齐（默认 `114,114,114`，即 YOLO letterbox 灰，可自由改色，色块实时预览）。
- 开启后导出文件名追加 `_pad` 后缀，便于区分两种口径的产物；填充色本身不进文件名。
- 预览区会把补边区域按所选颜色画出来。

**模板**

顶部第三列展示最近 3 次使用的参数组合（含填充设置），点击直接套用，行列按当前图与锁定状态自动重算，跨会话保留。按钮文字形如 `800×640·重叠200·50%`，正方形追加 `·正方形`，开启填充追加 `·补边`。

套用带填充的模板时同样受 30% 补边上限约束：模板里的宽高若在当前图上超限，会**吸附到最近的合规值**并在摘要行提示。

**取消全选**

「数据增强」区「跳过空标签」右侧的「取消全选」按钮，一键取消所有已勾选的增强方式（含原图与滑窗裁剪），便于从零重新挑选组合。


### 10.2 数据导出

将 LabelMe JSON 标注导出为选定格式。

- **导出格式**：下拉框可选 `YOLO Detection` / `YOLO Seg` / `YOLO Pose` / `YOLO OBB` / `VOC Detection` / `COCO Detection`
- **类别选择**：自动扫描当前标注的所有标签类别，以复选框列出，可自由选择要导出的类别
- **输出结构**：
  - `exports/images/` — 图片（优先使用增强后的图片）
  - `exports/labels/` — 对应的 `.txt` 标签文件
  - `exports/classes.txt` — 类别列表文件
- **跳过空标签**：默认勾选，跳过没有检测框的图片
- 支持操作中断和清空输出

各 YOLO 任务的行格式：

| 任务 | 每行格式 | 说明 |
|------|---------|------|
| Detection | `cls cx cy w h` | 水平框中心 + 宽高（归一化） |
| Seg | `cls x1 y1 x2 y2 ... xn yn` | 多边形顶点（归一化），少于 3 点跳过 |
| Pose | `cls cx cy w h x1 y1 v1 ... xn yn vn` | 人体框 + 关键点（归一化）+ 可见性；按 `group_id` 组合，缺少框或关键点的实例跳过 |
| OBB | `cls x0 y0 x1 y1 x2 y2 x3 y3` | 旋转框 4 顶点（归一化），逆时针顺序 |

> 当图片含多种形状类型时，导出会按所选任务提示：不匹配的形状被跳过（输出提示日志），若没有任何匹配形状则报错，避免静默产生空标签文件。导出前请确认任务与标注类型一致（例如选 `YOLO Seg` 才能导出多边形）。

### 10.3 格式转换

点击工具栏「格式」按钮打开独立窗口，用于在数据集格式之间互转。

- **输入格式 / 输出格式**：均在 `YOLO` / `COCO` / `Pascal VOC` / `LabelMe` 之间选择，默认 LabelMe → YOLO
- **任务类型**：选择 `检测框 (det)` / `分割 (seg)` / `旋转框 (obb)` / `关键点 (pose)`，仅在输出为 YOLO 时决定行格式；其他输出格式按水平框处理
- **图片目录 / 输出目录**：指定待转换图片与标注目录、输出位置
- 转换前会做一致性校验，混合形状类型时给出跳过提示或错误

> 该窗口只做格式转换，不执行增强或划分。需要增强后再导出，请使用「增强划分」面板。

### 10.4 KMeans 划分

基于标签的**出现频次**和**平均检测框面积**二维特征，通过 KMeans 聚类将数据集自动划分为多个分组，支持训练/验证/测试拆分。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| Train | 0.8 | 每个分组内训练集比例 |
| Val | 0.2 | 每个分组内验证集比例 |
| K | 自动推荐 | 自动以轮廓系数评估推荐最优 K，也可手动调整 |

**使用流程**：
1. 在导出菜单选择「KMeans 划分」
2. 选择待分析的图片目录
3. 点击「开始分析」，系统遍历标签并显示聚类指数窗口
4. 确认 K 值后点击「开始分类」，自动聚类并执行划分
5. 输出至源图片目录，结构如下：

```
{image_dir}/
├── g0/
│   ├── images/
│   │   ├── train/
│   │   └── val/
│   ├── labels/
│   │   ├── train/
│   │   └── val/
│   ├── classes.txt
│   └── {folder_name}_g0.yaml
├── g1/
│   └── ...
```

每个分组包含独立的 `classes.txt`（仅含该组出现的标签）和 YOLO 格式的 `_g{i}.yaml`配置文件。支持操作中断和重新分析。

### 10.5 数据集划分

将 YOLO 导出后的数据集按训练/验证/测试比例划分至 `exports/divide/` 目录。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| Train | 0.8 | 训练集比例 |
| Val | 0.1 | 验证集比例 |
| Test | 0.1 | 测试集比例 |

- 比例自动约束：调整任意一个时，超出部分会从其他比例中扣减，确保单个比例不超过可分配上限
- 划分会检查图片数量与标签数量是否一致
- 支持操作中断和清空输出

## 11. 网格辅助线

- 按 `Ctrl+G` 显示/隐藏网格
- 网格为虚线点阵，默认间距 50px
- 可在设置对话框中调整线宽（1~10）和透明度（0~255）
- 缩放间距 < 5px 时自动隐藏
- 深色/浅色主题使用不同颜色值

## 13. 命令行启动

可以直接带参数启动，跳过手动打开目录的步骤：

```bash
LabelForge.exe D:\data\images                          # 打开背景图目录
LabelForge.exe D:\data\images --labels D:\classes.txt  # 同时导入背景标签文件
LabelForge.exe --labels D:\classes.txt                 # 只导入标签
LabelForge.exe --version                               # 显示版本号
LabelForge.exe --help                                  # 显示用法
```

| 参数 | 说明 |
|------|------|
| `path` | 可选，启动后直接打开的背景图目录 |
| `--labels 文件` | 可选，启动后导入的背景标签文件（每行一个类别，与扫描结果取并集） |
| `--version` | 打印版本号后退出 |
| `--help` | 打印用法后退出 |

> 路径不存在时会在状态栏提示，不会静默失败。
> 打包后的 exe 为 GUI 子系统，`--version` / `--help` 的输出在终端中不显示；需要查看输出时请用源码方式运行 `python -m labelforge.main --version`。

## 常见问题

### 启动报错 ModuleNotFoundError
```bash
pip install -r requirements.txt
```

OpenCV 的不同发行包共用 `cv2`，同一环境只保留一种。新环境默认安装 `opencv-python-headless`；已有可用的官方 OpenCV 时可复用，避免重复安装不同发行包。

### 启动 exe 缺少 ffi.dll
Windows 深色标题栏依赖 `ffi.dll`。使用 `labelforge/build.sh` 打包会自动包含，或手动复制 `<conda_env>/Library/bin/ffi.dll` 到 exe 同目录。

### 贴图不显示
确认已加载贴图，滚轮放大视图，检查贴图是否在画布范围外。

### 检测框无法绘制
确认已按 `W` 进入绘制模式，在背景图范围内拖动，框需大于 3×3 像素。

### 保存失败
检查输出目录写权限、磁盘空间、文件名合法性。

### 一键贴图无反应
确认已加载背景图和贴图，从当前图片开始处理。

### 标签删除后消失
删除标签会级联移除所有使用该标签的检测框。保存后 JSON 同步更新。

### 发生未处理异常或 Qt 报错
未处理异常和 Qt 消息会写入用户主目录的 `~/labelforge.log`，可将该日志用于排查问题。
