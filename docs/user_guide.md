## 界面布局

PasteLabel 界面分为四个区域：

1. **工具栏**（顶部）— 背景图/贴图/标签加载按钮，标注/贴图模式切换，记忆、选项、缓存、统计、质检、格式、导出按钮，以及最右侧的语言/主题/设置按钮
2. **画布区域**（左侧）— 显示背景图、贴图、检测框，支持缩放/平移/绘制
3. **控制面板**（右侧）— 背景图列表（步长翻页 + 工作/移除路径切换 + 任务/分组筛选）、标签列表、贴图列表、操作按钮
4. **状态栏**（底部）— 实时显示鼠标坐标/贴图数/检测框数/标签统计

---

## 1. 贴图/标注模式切换

工具栏右侧的双栏滑动切换控件，控制画布交互的优先级。**软件默认打开为标注模式。**

| | 标注模式（默认） | 贴图模式 |
|---|---|---|
| **悬停高亮** | 鼠标移到检测框上自动选中 | 鼠标移到贴图上自动选中 |
| **左键优先级** | 检测框 → 贴图项 → 背景 | 贴图项 → 检测框 → 背景 |
| **画布内放大预览** | 开启后，选中检测框或绘制时，鼠标位于背景图内自动显示 | 不显示 |

切换时状态栏显示 `Mode: Annotate` / `Mode: Paste`（2秒后消失）。

## 2. 背景图片管理

### 加载背景图片
- **单张加载**：点击「背景图」图标按钮，选择图片
- **批量加载**：点击文件夹图标，选择图片文件夹（自然排序）
- 加载数千张的大数据集时，列表会快速填充，标注状态图标随后逐行点亮，加载过程界面保持响应

### 切换背景图片
- 点击背景图列表中的图片
- 或使用快捷键：`D` 下一张、`A` 上一张
- **步长设置**：数字滚轮 1~10，每次翻页的图片数量

### 列表路径显示
- 默认显示完整绝对路径
- 在「选项」菜单最下方勾选 **相对路径显示**，改为显示相对路径（如 `images\1.png`），便于迁移数据集
- 以已加载文件夹的父目录为基准；跨盘符时自动回退为绝对路径
- 设置会写入配置文件，下次启动保持

### 复制图片路径（右键）
在背景图列表中**右键**任意一项，选择「复制图片路径」，即可把该图片的**全局绝对路径**复制到剪贴板。

> 无论「相对路径显示」是否开启，复制的都是完整绝对路径。

### 工作路径 / 移除路径
- 点击「工作路径」/「移除路径」按钮切换视图
- 工作路径：显示参与标注的图片，所有操作可用
- 移除路径：显示被移除的图片，右键仅可恢复，W/Q/Delete 快捷键禁用
- 移除路径为空时可安全切换，不会报错

### 标注状态筛选

点击背景图列表右侧的筛选按钮，在工作路径下循环切换筛选模式：

| 模式 | 图标 | 说明 |
|------|------|------|
| 全部 | 三色圆点 | 显示所有图片（默认） |
| 已标注 | 绿色实心圆 | 仅显示已有检测框的图片 |
| 未标注 | 灰色空心圆 | 仅显示没有 JSON 标注文件的图片 |
| 空标签 | 橙色中心点空心圆 | 仅显示有 JSON 但无检测框内容的图片 |

切换筛选时自动导航到首个可见图片。筛选仅在工作路径下生效，进入移除路径时自动隐藏筛选按钮。

> 标注状态按图片对应的 LabelMe JSON 文件判断：存在且有 shapes 为「已标注」，存在但为空 shapes 为「空标签」，不存在为「未标注」。

### 按任务 / 按分组筛选

背景图列表右侧除状态筛选外，还有两个筛选按钮（均为多选菜单）：

- **按任务筛选** — 按形状类型筛选，可勾选 `det` / `seg` / `pose` / `obb`，只看含对应形状的图片；菜单底部「全部」清空选择
- **按分组筛选** — 按当前图的 `group_id` 筛选，可勾选具体分组号或「未分组」；菜单底部「全部」清空选择

两者可叠加生效，勾选状态显示在按钮提示中。

### 刷新背景列表

在文件夹外新增或删除图片后，点击背景图列表右上角的 **刷新** 图标按钮，即可就地同步列表：

- 重新扫描**当前已加载的文件夹**（不弹文件夹选择框），按文件名自然排序比对
- 新增的图片追加到列表，已删除的图片从列表移除；其余项原地保留
- **不会**重新导入、**不会**丢失内存中未保存的检测框/画布项——它们按路径迁移到新索引
- 当前选中图优先按路径找回，找不到才回到列表首项
- 列表行只做轻量装饰（仅判断文件是否存在），类别集合与状态图标由后台扫描补齐，因此比重新选择文件夹快得多
- 结果在状态栏提示 2 秒：无变化显示「文件夹无变化」，有变化显示「新增 X 张 · 移除 Y 张」

> 尚未加载任何文件夹、或文件夹已不可读时，仅在状态栏提示，不弹对话框。

### 拖拽操作
- **拖入**：将图片（PNG/JPG/BMP/GIF）或 LabelMe JSON 拖入窗口，自动加载
- **拖出**：从画布按住左键拖到窗口外，复制当前背景图到桌面/文件夹

## 3. 记忆

点击工具栏「记忆」按钮打开最近素材记录窗口。

### 自动记录
- 关闭软件时自动保存当前背景图路径 + 贴图路径 + 标签文件路径 + 图片索引
- 最多 10 组记录，按路径组合去重（同一组再次使用时更新到顶部）

### 操作
- **加载** — 清空当前素材后加载该组记录，自动跳到记录的图片序号
- **修改备注** — 按任务/数据集/客户名填写备注
- **删除** — 删除选中记录

## 4. 贴图功能

### 加载贴图
- **单张/批量**：点击「贴图」图标按钮，选择贴图文件
- **文件夹加载**：点击文件夹图标，选择贴图文件夹

### 手动贴图
1. 在贴图列表中点击贴图 → 自动放置到背景中心
2. 鼠标拖动调整位置
3. 滚轮缩放 或 拖拽右下角手柄调整大小

### 随机贴图
1. 设置参数：**贴图个数**（1~20）、**短边尺寸范围**（最小 15~100，最大 30~200）
2. 点击「随机贴图」— 中心点避让算法自动放置，避免与检测框/已贴图重叠

### 一键贴图（批量）
点击「一键贴图」，从当前图片开始逐张执行随机贴图，弹出进度条。

### 语义区域放置

在画布上绘制"语义区域"（矩形或多边形），随机贴图时贴图**完整落在**这些区域内，使合成样本符合画面语义（例如"车只贴在路面区域"）。

**入口**：画布**右键菜单**，**仅在贴图模式**出现（标注模式没有）。不新增按钮。

**添加矩形区域**：
1. 右键画布空白处 → 菜单选择「添加区域（矩形）」
2. 左键**按下**定起点，拖动预览，**松开左键**完成

**添加多边形区域**：
1. 右键画布空白处 → 菜单选择「添加区域（多边形）」
2. 左键**逐点**点击添加顶点（与多边形标注一致）
3. **右键 / 回车 / 双击**完成绘制（至少 3 个点）
4. `Backspace` 撤销上一个点

两种绘制均可按 `Esc` 取消。

**编辑区域**：贴图模式下**直接**可编辑（无需进入编辑模式）
- 拖动区域内部：整体移动
- 矩形拖动四角手柄 / 多边形拖动顶点圆点：缩放、调整形状
- 多边形点击边线：插入新顶点；右键顶点：删除顶点
- **鼠标悬停在区域上滚动滚轮**：绕中心缩放
- 均夹紧到图片边界，最小边长 10 像素

**固定区域**：右键菜单中的全局开关。固定后所有区域锁定（不能拖动/缩放/滚轮/顶点编辑/删除/新增/清空），但仍约束贴图落点。

**删除区域**：右键区域 → 删除区域；或右键空白处 → 清空区域（有二次确认）一次删全部。

**层级**：区域绘制在贴图**下方**（贴图会覆盖区域框）。

**外观**：青色虚线框，选中时加粗 + 淡填充 + 手柄圆点。

**跨图共享**：所有区域在所有图片间共享一套（关软件后消失，不保存到文件）。

**不持久化**：区域仅运行时存在，不写入 JSON、不导出、不影响标签。

**作用范围**：只约束「随机贴图」和「一键贴图」；手动单张添加贴图不受约束。区域装不下贴图时该次贴图跳过。无区域时，随机贴图行为与以前完全一样。

### 贴图列表视图
- 缩略图视图（预览缩略图） ↔ 列表视图（显示文件名）

## 5. 标签管理

### 加载标签

工具栏「标签:」处有两个导入按钮：

| 按钮 | 图标 | 说明 |
|------|------|------|
| 背景标签导入 | 文件 + 下箭头 | 导入背景图标签文件，与扫描结果**取并集** |
| 贴图标签导入 | 文件 + 标签框 | 导入贴图标签文件 |

两者都读取文本文件（每行一个标签，也兼容 `类别 x y w h` 这类带额外列的行，只取第一列）。

**背景标签导入**的特点：

- 与从背景图 JSON 中扫描出的类别**取并集**，导入的类别不会被后续扫描覆盖，扫描出的类别也不会挤掉导入的类别
- 重复导入自动去重
- 文件为空时提示「未找到有效的标签」，读取失败时提示错误，均不改变现有类别
- 更换数据集或清空素材时，导入的类别一并清空

### 列表模式切换

背景图标签列表支持两种显示模式，点击标签列表标题行的模式切换按钮切换：

| 模式 | 说明 |
|------|------|
| 统计计数 | 按标签类别汇总显示数量，按数量降序排列（默认） |
| 每框一行 | 列出当前图片的每个检测框，每一行是一个框，显示标签名和位置信息，支持右键单独修改/删除 |

- 统计模式下右键修改/删除标签会级联操作所有使用该标签的检测框
- 每框一行模式下右键修改/删除仅影响选中的单个检测框

### 标签列表操作（右键）
两个标签列表都支持右键菜单：

| 操作 | 背景图标签 | 贴图标签 |
|------|-----------|---------|
| 增加标签 | 输入新名称，加入全局标签 | 输入新名称，加入贴图标签列表 |
| 修改标签 | 重命名，级联更新所有检测框 JSON | 重命名，级联更新所有使用该标签的贴图项 |
| 删除标签 | 删除，级联移除所有背景图中使用该标签的检测框 | 删除，级联移除使用该标签的贴图项 |

> 标签列表按数量降序排列，统计仅计算工作路径的图片。可通过列表标题行按钮在「统计计数」和「每框一行」两种模式间切换。
> 带有分组的形状在列表中显示为 `标签名 [分组号]`。

### 快捷键删除标签

选中标签列表中的某一项后，按 `Ctrl+Shift+Z` 可直接删除，**不弹确认框**，适合连续清理标签。

- 统计计数模式：删除该标签在所有背景图中的全部检测框
- 每框一行模式：只删除选中的那一个检测框

> 右键菜单的「删除标签」仍会弹确认框，两者行为一致，只是快捷键跳过确认。快捷键可在设置中修改（位于「恢复图片」下方）。

### 自动添加标签
勾选「贴图标签」复选框后，添加贴图时自动从文件名提取标签（按 `_` 拆分取第一部分）。

## 6. 标注操作

PasteLabel 支持四种标注形状，均以 LabelMe 格式保存到 JSON 的 `shapes` 字段：

| 形状 | `shape_type` | 快捷键 | 说明 |
|------|-------------|--------|------|
| 水平检测框 | `rectangle` | `W` | 常规轴对齐矩形框 |
| 分割多边形 | `polygon` | `P` | 逐点勾勒目标轮廓，用于分割任务 |
| 姿态关键点 | `point` | `K` | 单点标注，可配合分组组成姿态实例 |
| 旋转框 (OBB) | `rotation` | `O` | 可任意角度旋转的矩形框 |

> `shape_type` 缺省时按 `rectangle` 处理，兼容旧版 JSON。
> 所有标注共用同一套标签、分组和撤销/重做机制。

### 画布内放大预览
开启「窗口放大器」后，标注模式下画布内显示鼠标附近的放大预览，辅助精准绘制与调整。放大倍率可在设置对话框中调节（0.8× ~ 3.0×）。

位置模式（设置 → 窗口放大器 → 位置）：
- **侧边（默认）** — 放大窗口在鼠标右下方偏移显示，仅选中检测框或绘制时激活
- **跟随鼠标** — 放大窗口以鼠标为中心显示，始终可见（无需选中框）

### 分组的用途

`group_id` 是一个整数分组标识，用于把多个形状关联为一个实例，典型场景是姿态关键点：一个人体框 + 若干关键点共用同一 `group_id`。所有形状类型均可选择性地填写分组号。

- 标签列表中有分组的项显示为 `标签名 [分组号]`
- 背景图列表可按任务、按分组筛选
- YOLO 姿态导出按 `group_id` 组合人体框与关键点

### 绘制检测框（水平框）

1. 点击「绘制 BOX(W)」或按 `W` 键进入绘制模式
2. 在背景图上按住鼠标左键拖动
3. 释放鼠标完成绘制
4. 弹出标签选择对话框，选择/输入标签，可填写分组号

> 检测框最小 3×3 像素。

### 绘制分割多边形

1. 按 `P` 进入多边形绘制模式
2. 依次**左键单击**添加顶点（最多 32 个），鼠标移动显示临时连线
3. 完成绘制（任选其一）：
   - **双击**最后一个顶点
   - 按 `Enter`
   - 在画布上**右键**
4. 至少需要 3 个顶点才能闭合；弹出标签选择对话框

绘制过程中：
- `Backspace` — 撤销最后一个顶点（只剩 1 个点时再次按下则取消整个绘制）
- `Esc` — 取消当前绘制
- `Q` — 退出绘制模式

选中多边形后：
- 拖动顶点可修改轮廓
- 在多边形边上**左键单击**可插入顶点
- 在顶点上**右键**选择「删除顶点」可删除该顶点（至少保留 3 个顶点）

### 标注关键点

1. 按 `K` 进入关键点标注模式
2. 在目标位置**左键单击**放置关键点
3. 弹出标签选择对话框，选择关键点名称并填写分组号（同一实例的关键点使用同一分组号）

选中关键点后可拖动调整位置。

### 绘制旋转框（OBB）

1. 按 `O` 进入旋转框绘制模式
2. 按住左键拖动确定初始矩形（先创建为水平状态），释放后弹出标签选择对话框
3. 选中该旋转框后，拖动框中心的旋转手柄调整角度，或用 `Z`/`X` 逐步旋转

选中旋转框后：
- 拖动 4 个顶点可调整形状（保持矩形）
- 拖动旋转手柄可旋转
- 按 `Z` 顺时针旋转、`X` 逆时针旋转，每次旋转角度由设置中的「旋转角度步长」决定（1~6°，默认 1°）
- 标签名旁显示当前角度（如 `text 45°`）

### 调整检测框
- **选中**：点击检测框
- **移动**：拖动检测框
- **缩放**：拖动四角手柄（绿色方块）；选中后在框内滚动滚轮可等比缩放，框外滚动则调整距离鼠标最近的一条边
- **滚轮参数**：框内缩放步长和框外单侧位移像素均可在设置对话框中调整

### 标注十字线
- 仅在标注模式、鼠标位于画布内且背景图已显示时出现
- 可在设置对话框调整粗细（0.5~3.0）、透明度（0~255）和颜色

### 显示/隐藏
- 显示/隐藏检测框边框：`R` 键 或 选项菜单
- 显示/隐藏标签名称：`T` 键 或 选项菜单

## 7. 右键菜单

### 画布右键

| 点击位置 | 菜单内容 |
|---------|---------|

| 问题类型 | 判定 |
|---------|------|

## 10. 数据处理

点击工具栏「导出」按钮打开数据处理面板，为独立浮动窗口，可关闭。面板顶部为数据集目录选择器，默认使用当前背景图所在目录；**切换数据集（含从记忆记录载入）后该目录会自动跟随新数据集**，输出目录随之改到新数据集的父目录下，不会再把结果导进上一个数据集的 `exports/`；只有数据集发生变化时才自动写入，因此你手动指定过的路径不会被切语言之类的无关刷新冲掉。输出目录在数据目录的父目录下自动创建 `exports/` 子目录；面板底部有操作日志区域，显示实时进度条和日志。

### 10.1 数据增强

对数据集图片进行批量变换，同步生成增强后的图片与 JSON 标注。

| 参数 | 说明 |
|------|------|
| 变换种类 | 支持 12 种变换：水平翻转、垂直翻转、亮度、对比度、色相(H)、饱和度(S)、明度(V)、高斯噪声、椒盐噪声、随机平移、随机旋转、随机缩放，每种可独立勾选启用，部分变换配有参数范围（最小 ~ 最大） |
| 滑窗裁剪 | 勾选后把高分辨率图按固定尺寸切为多个带重叠的子图（默认按首图反推出 **2 行 × 3 列** 的网格，重叠默认为窗口的 **15%**），跨窗标注按最小可见比例（默认 70%，低于丢弃；可调范围 50%~100%）过滤，空窗不落盘；点「配置…」打开参数小窗（锁定联动、边缘填充、模板、实时预览），详见下方「滑窗裁剪参数小窗」；输出 `{原名}_crop_r{行}c{列}_ov{重叠值}` 子图与 JSON，开启边缘填充时追加 `_pad` |
| 原图 | 可选是否将原图一并写入增强结果 |
| 图片比例 | 0.05 ~ 1.0，控制增强图片数量相对原图的比例 |
| 模式 | **全部增强** — 对所有图片应用所有已选中的变换；**随机几项** — 每次随机选取部分变换组合 |

增强结果保存至 `exports/images/`，图片与对应 JSON 标注同步增强。支持操作中断和清空输出。

#### 滑窗裁剪参数小窗

布局为**上中下三段**：顶部参数区按三列并排（尺寸/重叠/数量 · 可见比例/边缘填充/预览图 · 模板），中部是占满宽度的实时预览，底部是红绿图例与「确定 / 取消」。预览把各窗口拆成分离小图并排展示且均显示图像内容，**绿框=保留，红框=空窗丢弃**；摘要行给出「共 N 图 · 预计产出 M 张」。

**三组量的联动**

窗口尺寸（宽/高）、重叠长度、裁剪数量（按**行 × 列**显示）三者满足 `n × 尺寸 − (n−1) × 重叠 ≥ 边长`。**宽高是自变量**：你想切成多大就设多大，另外两项按下面的规则跟上。

- **未开边缘填充**：宽高与重叠**互相反推**。改宽高 → 反推出一个让该轴恰好铺满的重叠，另一轴再按这个重叠取到也恰好铺满的尺寸；改重叠 → 两轴尺寸一起反推。于是网格**始终恰好铺满**整幅图，末行末列窗口都贴边，不多切也不少切。改数量则保持当前重叠反推尺寸。
  - 恰好铺满要求 `n × 尺寸 − (n−1) × 重叠 = 边长` 有整数解。宽轴能解时优先由宽轴驱动，另一轴由该重叠反推；某轴无整数解时该轴保持不动（不硬凑），摘要行会显示实际行列数。
  - 由于重叠两轴共用一个像素值，两轴未必都能同时精确铺满；能解的那轴精确铺满，另一轴取到能排出该数量的最小窗口（末窗仍贴边）。
- **开启边缘填充**：**不反推**。宽高就是你设的值，不够的部分由填充补上，重叠保持不动。等步长落位下两轴不可能都精确铺满，所以此时不追求同步，差多少补多少。
  - 补边不得超窗口的 30%，超限时**只动重叠、不动你设的宽高**（详见下方「补边上限 30%」）。
- 另有「正方形」勾选可锁定宽高相等。

**补边上限 30%**

开启边缘填充后，补边量**不得超过窗口宽/高的 30%**（否则切出来几乎全是灰边，等于废图）。这是**硬约束**：任何入口（手动输入、改重叠、改数量、套模板、换图、打开小窗）都不会让超限值留在界面上。

- 上限对**每一轴**独立生效：宽轴补边 ≤ 窗口宽的 30%，高轴同理；重叠两轴共用一个值，故须**同时**满足两轴。
- **超限值吸附**：当前组合超限时，改的是**重叠**（宽高是你设的自变量，不动），吸附到最近的两轴同时合规值；距离相同时取较小值。确实吸附过时，摘要行给出 ⚠ 提示，调到合规值后提示自动消失。
- **硬墙**：宽高与重叠的输入范围会被钳到「当前值所在的那一段合规区间」，用鼠标/键盘都拖不出超限值。合规集合在固定重叠下是**锯齿状多段**（窗口数每变一次补边就跳回 0，例如 600 图上重叠 60 时有 15 段），所以墙是按「当前所在段」设的，而不是只钳最外端——否则你会停在两段之间的空洞里。
- 重叠的合规段还会**叠加「半窗」上限**（未锁数量时），两个上限同时生效。
- 锁定「重叠 + 数量」时：尺寸可行区间直接排除补边超限的组合，区间会比不开填充时更窄；关掉填充后区间立刻恢复原状。

**默认值**

首次配置（尚无已保存参数）时，按当前首图尺寸反推出恰好 **2 行 × 3 列** 的窗口尺寸，重叠取窗口的 **15%**。重叠两轴共用一个像素值，无法在两轴上都恰好等于 15%，故以**较小窗口边**为基准（更保守，也不会撞上「未锁数量时重叠不超过半窗」的上限）。换用不同尺寸的数据集后，默认值会跟着重算，网格始终保持 2×3；尚未加载数据集时按 640×640 名义尺寸计算。

**锁（每组量右侧的 🔒 图标按钮）**

- 🔓 点击上锁、🔒 点击解锁；锁定的量成为约束，联动时**永不被自动改动**，未锁的量按锁定项反推。
- 最多同时锁 **2** 组；锁第 3 组时自动解开**最早锁的那一组**（按点击先后轮转）。
- 锁满 2 组后，第三项**并非唯一确定**，而是一段**可行区间**：
  - 锁「重叠 + 数量」→ 尺寸可编辑，输入范围自动收窄到所有能排出该数量的尺寸（例：1920 图上锁 3 列、重叠 88，尺寸可在 699~1003 之间自由调，列数始终是 3）
  - 锁「尺寸 + 数量」→ 重叠同理可编辑，范围取宽高两轴可行区间的**交集**（重叠两轴共用一个值）
  - 锁「尺寸 + 重叠」→ 数量是纯结果、没有自由度，输入框才置灰只读
- 解锁后输入范围立即恢复原状（尺寸 8~8192、重叠回到半窗口径）。
- 常见用法：锁「数量」+ 锁「重叠」→ 尺寸在可行区间内自由挑；锁「尺寸」+ 锁「重叠」→ 数量自动算出。
- 锁定「数量」时，重叠上限从「半窗」放宽到「窗口 − 1」（数量已锁死，窗口数不会爆炸）。
- 若当前尺寸/重叠凑不出锁定的数量，会按最接近的可行值调整，并在摘要行给出 ⚠ 提示。
- 锁定状态是临时的：不写入模板、不跨会话保留。

**边缘填充**

- **关闭（默认）**：窗口尺寸被压缩到不超过图像，末行/末列窗口贴边排布，不越界。
- **开启**：窗口尺寸**严格固定**，按等步长（步长 = 尺寸 − 重叠）排布；末行/末列窗口可越出图像右/下边缘，越界部分用右侧 RGB 颜色补齐（默认 `114,114,114`，即 YOLO letterbox 灰，可自由改色，色块实时预览）。
- 开启后导出文件名追加 `_pad` 后缀，便于区分两种口径的产物；填充色本身不进文件名。
- 预览区会把补边区域按所选颜色画出来，所见即所得。

**模板**

顶部第三列展示最近 3 次使用的参数组合（含填充设置），点击直接套用，行列按当前图与锁定状态自动重算，跨会话保留。按钮文字形如 `800×640·重叠200·50%`，正方形追加 `·正方形`，开启填充追加 `·补边`。

套用带填充的模板时同样受 30% 补边上限约束：模板里的宽高若在当前图上超限，会**吸附到最近的合规值**并在摘要行提示（宽高会按模板值先原样回填，再统一收口，不会带着旧范围被截断）。

**取消全选**

「数据增强」区「跳过空标签」右侧的「取消全选」按钮，一键取消所有已勾选的增强方式（含原图与滑窗裁剪），便于从零重新挑选组合。


### 10.2 数据导出

将 LabelMe JSON 标注导出为选定格式。

- **导出格式**：下拉框可选 `YOLO Detection` / `YOLO Seg` / `YOLO Pose` / `YOLO OBB` / `VOC Detection` / `COCO Detection`
- **类别选择**：自动扫描当前标注的所有标签类别，以复选框列出，可自由选择要导出的类别
- **输出结构**：
  - `exports/images/` — 图片（优先使用增强后的图片）
  - `exports/labels/` — 对应的 `.txt` 标签文件
  - `exports/classes.txt` — 类别列表文件
- **跳过空标签**：默认勾选，跳过没有检测框的图片
- 支持操作中断和清空输出

各 YOLO 任务的行格式：

| 任务 | 每行格式 | 说明 |
|------|---------|------|
| Detection | `cls cx cy w h` | 水平框中心 + 宽高（归一化） |
| Seg | `cls x1 y1 x2 y2 ... xn yn` | 多边形顶点（归一化），少于 3 点跳过 |
| Pose | `cls cx cy w h x1 y1 v1 ... xn yn vn` | 人体框 + 关键点（归一化）+ 可见性；按 `group_id` 组合，缺少框或关键点的实例跳过 |
| OBB | `cls x0 y0 x1 y1 x2 y2 x3 y3` | 旋转框 4 顶点（归一化），逆时针顺序 |

> 当图片含多种形状类型时，导出会按所选任务提示：不匹配的形状被跳过（输出提示日志），若没有任何匹配形状则报错，避免静默产生空标签文件。导出前请确认任务与标注类型一致（例如选 `YOLO Seg` 才能导出多边形）。

### 10.3 格式转换

点击工具栏「格式」按钮打开独立窗口，用于在数据集格式之间互转。

- **输入格式 / 输出格式**：均在 `YOLO` / `COCO` / `Pascal VOC` / `LabelMe` 之间选择，默认 LabelMe → YOLO
- **任务类型**：选择 `检测框 (det)` / `分割 (seg)` / `旋转框 (obb)` / `关键点 (pose)`，仅在输出为 YOLO 时决定行格式；其他输出格式按水平框处理
- **图片目录 / 输出目录**：指定待转换图片与标注目录、输出位置
- 转换前会做一致性校验，混合形状类型时给出跳过提示或错误

> 该窗口只做格式转换，不执行增强或划分。需要增强后再导出，请使用「增强划分」面板。

### 10.4 KMeans 划分

基于标签的**出现频次**和**平均检测框面积**二维特征，通过 KMeans 聚类将数据集自动划分为多个分组，支持训练/验证/测试拆分。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| Train | 0.8 | 每个分组内训练集比例 |
| Val | 0.2 | 每个分组内验证集比例 |
| K | 自动推荐 | 自动以轮廓系数评估推荐最优 K，也可手动调整 |

**使用流程**：
1. 在导出菜单选择「KMeans 划分」
2. 选择待分析的图片目录
3. 点击「开始分析」，系统遍历标签并显示聚类指数窗口
4. 确认 K 值后点击「开始分类」，自动聚类并执行划分
5. 输出至源图片目录，结构如下：

```
{image_dir}/
├── g0/
│   ├── images/
│   │   ├── train/
│   │   └── val/
│   ├── labels/
│   │   ├── train/
│   │   └── val/
│   ├── classes.txt
│   └── {folder_name}_g0.yaml
├── g1/
│   └── ...
```

每个分组包含独立的 `classes.txt`（仅含该组出现的标签）和 YOLO 格式的 `_g{i}.yaml`配置文件。支持操作中断和重新分析。

### 10.5 数据集划分

将 YOLO 导出后的数据集按训练/验证/测试比例划分至 `exports/divide/` 目录。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| Train | 0.8 | 训练集比例 |
| Val | 0.1 | 验证集比例 |
| Test | 0.1 | 测试集比例 |

- 比例自动约束：调整任意一个时，超出部分会从其他比例中扣减，确保单个比例不超过可分配上限
- 划分会检查图片数量与标签数量是否一致
- 支持操作中断和清空输出

### 10.6 一键流水线

- 可勾选需要执行的步骤（增强、导出、划分），至少选中 2 步
- 点击「▶ 一键流水线」按顺序依次执行

### 10.7 中断功能

每个操作按钮旁有红色 ■ 中断按钮，操作进行中可见。中断后当前步骤停止；若在一键流水线中中断，则流水线终止。

### 10.8 面板与窗口保护

- 面板关闭时清除日志并隐藏，再次打开显示空白日志面板
- 面板打开且可见时，关闭主窗口会弹出提示「数据处理正在进行中，无法关闭主界面」

### 10.9 画布加载指示器

加载大量图片时，画布区域显示加载动画（旋转字符 + 「识别中...」），加载完成后自动消失。

## 13. 命令行启动

可以直接带参数启动，跳过手动打开目录的步骤：

```bash
PasteLabel.exe D:\data\images                          # 打开背景图目录
PasteLabel.exe D:\data\images --labels D:\classes.txt  # 同时导入背景标签文件
PasteLabel.exe --labels D:\classes.txt                 # 只导入标签
PasteLabel.exe --version                               # 显示版本号
PasteLabel.exe --help                                  # 显示用法
```

| 参数 | 说明 |
|------|------|
| `path` | 可选，启动后直接打开的背景图目录 |
| `--labels 文件` | 可选，启动后导入的背景标签文件（每行一个类别，与扫描结果取并集） |
| `--version` | 打印版本号后退出 |
| `--help` | 打印用法后退出 |

> 路径不存在时会在状态栏提示，不会静默失败。
> 打包后的 exe 为 GUI 子系统，`--version` / `--help` 的输出在终端中不显示；需要查看输出时请用源码方式运行 `python -m pastelabel.main --version`。

## 常见问题

### 启动报错 ModuleNotFoundError
```bash
pip install PyQt5 opencv-python
```

### 启动 exe 缺少 ffi.dll
Windows 深色标题栏依赖 `ffi.dll`。使用 `pastelabel/build.sh` 打包会自动包含，或手动复制 `<conda_env>/Library/bin/ffi.dll` 到 exe 同目录。

### 贴图不显示
确认已加载贴图，滚轮放大视图，检查贴图是否在画布范围外。

### 检测框无法绘制
确认已按 `W` 进入绘制模式，在背景图范围内拖动，框需大于 3×3 像素。

### 保存失败
检查输出目录写权限、磁盘空间、文件名合法性。

### 一键贴图无反应
确认已加载背景图和贴图，从当前图片开始处理。

### 标签删除后消失
删除标签会级联移除所有使用该标签的检测框，这是设计行为。保存后 JSON 同步更新。

### 发生未处理异常或 Qt 报错
未处理异常和 Qt 消息会写入用户主目录的 `~/pastelabel.log`，可将该日志用于排查问题。
